# layout-fix

Фоновий демон для X11 і Cinnamon. Якщо слово набране не в тій розкладці, він стирає його на пробілі, перемикає джерело вводу і набирає ті самі клавіші іншою мовою. Підтримуються English (US), Ukrainian і Russian; перемикання відбувається лише коли підходить рівно один словник.

Демон читає події клавіатури в межах X11-сесії, тримає поточне слово в пам'яті й не записує його на диск. Звичайний журнал не містить набраного тексту. `--debug-keys` виводить символи в stderr, тому не вмикай його під час введення паролів чи інших секретів.

Керування з клавіатури й меню трея. Значок показує код поточної мови: зелений у роботі, сірий у паузі, помаранчевий — коли XKB і джерела Cinnamon тимчасово не узгоджені й виправлення призупинено. У меню є Pause/Resume, вибір джерела Cinnamon, налаштування, About і вихід:

- `Pause` ставить демон на паузу і знімає її. Під час паузи автоматичне виправлення, скасування та виправлення виділеного тексту не працюють. Перед паролем увімкніть паузу.
- `Shift+Pause` скасовує останнє виправлення, якщо після нього ще не почато наступне слово.
- `Alt+Pause` виправляє виділений текст через буфер обміну (зі збереженням попереднього вмісту буфера), або примусово виправляє останнє набране слово без виділення (зокрема короткі, власні чи двозначні слова; повторне натискання перебирає активні розкладки) і перемикає розкладку на цільову мову. У виключених вікнах (зокрема терміналах) не спрацьовує.

## Збірка

Потрібні пакети: `build-essential`, `cmake`, `pkg-config`, `libx11-dev`, `libxtst-dev`, `libxkbcommon-dev`, `libglib2.0-dev`, `hunspell-en-us`, `hunspell-uk`, `hunspell-ru`, `libhunspell-dev`, `qt6-base-dev`. Без `libhunspell-dev` демон перевіряє точні основи з `.dic`. Файли `.aff` автоматично підхоплюються поруч із `.dic`. Без Qt 6 Widgets tray menu недоступне, але гарячі клавіші та автоматичне виправлення працюють.

Зі встановленим системним `qt6-base-dev` (Qt 6.2+/6.4+) проєкт збирається і запускається без додаткових змінних середовища:

```bash
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
./build/layout-fix --check
./build/layout-fix
```

Для Linux-артефактів релізу виконай `scripts/build-release.sh`. Скрипт перевіряє словники, збирає Release (за замовчуванням із системним Qt 6, якщо встановлено `qt6-base-dev`), проганяє тести та створює versioned `.tar.gz` і `.deb` у `dist/`; версію бере з CMake. До кожного файла додається `.sha256`. Debian-пакет залежить від системних бібліотек (зокрема `libqt6widgets6t64 | libqt6widgets6` і `qt6-qpa-plugins`), тому після встановлення працює одразу:

```bash
sudo apt install ./dist/layout-fix_0.2.0_amd64.deb
systemctl --user daemon-reload
systemctl --user enable --now layout-fix.service
```

Якщо використовується нестандартний Qt (наприклад, із Qt Installer у `$HOME/Qt/...`), передай каталог `gcc_64` через `CMAKE_PREFIX_PATH` під час збірки та `QT_PREFIX` під час запуску:

```bash
export QT_PREFIX="$HOME/Qt/6.12.0/gcc_64"
cmake -S . -B build -DCMAKE_PREFIX_PATH="$QT_PREFIX"
QT_PREFIX="$QT_PREFIX" /usr/bin/layout-fix
```

Для user-service із нестандартним Qt задай `QT_PREFIX` у drop-in через `systemctl --user edit layout-fix`:

```ini
[Service]
Environment=QT_PREFIX=%h/Qt/6.12.0/gcc_64
```

`VERSION` можна передати в `scripts/build-release.sh`, якщо треба перевизначити CMake-версію.

`--check` з'єднується з X11, читає групи клавіатури і словники, потім виходить. Слухати клавіші він не починає.

## Запуск

У параметрах Cinnamon мають бути розкладки English (US) і Ukrainian. Якщо увімкнена Russian, демон також враховує її; коли словник приймає слово у двох мовах, перемикання не відбувається.

```bash
./build/layout-fix
```

Другий запуск нічого не робить: уже працює один примірник.

У меню трея можна призупинити або відновити роботу, вибрати доступне джерело Cinnamon, відкрити вікно налаштувань, переглянути About чи вийти. About показує версію та ліцензії коду й fallback-словника.

У налаштуваннях доступні мінімальна довжина слова, гарячі клавіші Pause / Undo / виправлення виділеного тексту (`convert-key`), список виключених вікон (`exclude`) і список слів-винятків (`ignore-words`, які ніколи не автовиправляються, без урахування регістру). Збережені зміни записуються в user config і застосовуються одразу. Якщо запускати з явним `--config PATH`, форма зберігає саме в цей файл; інакше використовує `~/.config/layout-fix/layout-fix.conf`, не перезаписуючи `/etc/xdg` config.

Популярні термінали (`gnome-terminal`, `terminator`, `xterm`, `alacritty`, `kitty`, `konsole`, `tilix`, `xfce4-terminal`, `wezterm`, `urxvt`, `mate-terminal`), менеджери паролів (`keepassxc`, `bitwarden`, `1password`), а також `cinnamon-screensaver`, `gcr-prompter` і сам `layout-fix` входять до типового списку винятків. Свій список лежить у `~/.config/layout-fix/layout-fix.conf` (зразок у `config/layout-fix.conf`) і редагується у вікні налаштувань, де також показується `WM_CLASS` останнього активного вікна з кнопкою швидкого додавання. Діалог пароля polkit малюється всередині Cinnamon і в цей список не потрапляє: перед ним увімкніть паузу.

Окреме коротке або двозначне (`uk`/`ru`) слово не чіпається. Контекст до чотирьох сусідніх слів виправляється разом, щойно наступне слово однозначно визначає мову (цільовий словник приймає всі слова, а поточний — не приймає хоча б одне). З `libhunspell-dev` враховуються словоформи за `.aff`; без нього працює точний збіг основи.

Після зміни списку джерел у Cinnamon демон перечитує XKB і `GetInputSources`. Поки індекси `us`/`ua` та ввімкненої `ru` не узгоджені, автоматичне виправлення призупиняється.

## Автозапуск

Для автозапуску використовуй user-сервіс systemd; CMake та Debian-пакет встановлюють launcher у відповідний `bin` каталог.

```bash
sudo cmake --install build
mkdir -p ~/.config/systemd/user
cp build/layout-fix.service ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now layout-fix.service
```

Після `cmake --install build` скопіюй згенерований `build/layout-fix.service` у `~/.config/systemd/user/`. Не додавай desktop autostart разом із сервісом: це створить другий запуск.
