# layout-fix

Фоновий демон для X11 і Cinnamon. Якщо слово або фраза набрані не в тій розкладці, демон стирає їх на межі слова, перемикає джерело вводу Cinnamon і підставляє текст потрібною мовою. Підтримуються English (US), Ukrainian і Russian; автоматичне перемикання відбувається лише коли підходить рівно один словник.

Демон читає події клавіатури в межах X11-сесії, тримає поточне слово в пам'яті й не записує його на диск. Звичайний журнал не містить набраного тексту. `--debug-keys` виводить символи в stderr, тому не вмикай його під час введення паролів чи інших секретів.

## Керування

Значок у треї показує код поточної мови: зелений у роботі, сірий у паузі, помаранчевий — коли XKB і джерела Cinnamon тимчасово не узгоджені й виправлення призупинено. У меню є Pause/Resume, вибір джерела Cinnamon, налаштування, About і вихід.

Типові гарячі клавіші (змінюються в налаштуваннях):

- `Pause` — ставить демон на паузу і знімає її. Під час паузи не працюють автовиправлення, скасування та виправлення виділеного тексту. Перед паролем увімкніть паузу.
- `Shift+Pause` — скасовує останнє виправлення, якщо після нього ще не почато наступне слово.
- `Alt+Pause` — виправляє виділений текст через буфер обміну (зі збереженням попереднього вмісту буфера й захистом від порожнього копіювання рядка у VS Code, JetBrains, Sublime тощо), або примусово виправляє останнє набране слово без виділення (короткі, власні чи двозначні слова; повторне натискання перебирає активні розкладки) і перемикає розкладку на цільову мову. У виключених вікнах не спрацьовує.

## Збірка

Потрібні пакети: `build-essential`, `cmake`, `pkg-config`, `libx11-dev`, `libxtst-dev`, `libxkbcommon-dev`, `libglib2.0-dev`, `hunspell-en-us`, `hunspell-uk`, `hunspell-ru`, `libhunspell-dev`, `qt6-base-dev`. Для ізольованого X11-тесту в `ctest` також використовується `xvfb` (`xvfb-run`).

Без `libhunspell-dev` демон перевіряє точні основи з `.dic` (файли `.aff` підхоплюються автоматично поруч із `.dic`). Без Qt 6 Widgets меню трея недоступне, але гарячі клавіші й автовиправлення працюють.

Зі встановленим системним `qt6-base-dev` (Qt 6.2+/6.4+) проєкт збирається і запускається без додаткових змінних середовища:

```bash
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
./build/layout-fix --check
./build/layout-fix
```

`--check` з'єднується з X11, читає групи клавіатури і словники, потім виходить без слухання клавіш.

Для Linux-артефактів релізу виконай `scripts/build-release.sh`. Скрипт перевіряє словники, збирає Release (за замовчуванням із системним Qt 6), проганяє `ctest` і створює `.tar.gz` та `.deb` у `dist/` із версією з CMake (або перевизначеною через `VERSION=...`), плюс `.sha256` до кожного файла. Debian-пакет залежить від системних бібліотек (`libqt6widgets6t64 | libqt6widgets6`, `qt6-qpa-plugins`, Hunspell, X11/XTest/xkbcommon/GLib) і сам додає автозапуск для Cinnamon (`/etc/xdg/autostart/layout-fix.desktop`):

```bash
sudo apt install ./dist/layout-fix_0.3.1_amd64.deb
```

Після встановлення `layout-fix` автоматично запускатиметься при кожному вході в Cinnamon (керується у стандартних «Програмах автозапуску»). Щоб запустити одразу в поточній сесії без перелогінення, відкрий **Layout Fix** у меню програм або виконай `layout-fix &`.

Якщо використовується нестандартний Qt (наприклад, із Qt Installer у `$HOME/Qt/...`), передай каталог `gcc_64` через `CMAKE_PREFIX_PATH` під час збірки та `QT_PREFIX` під час запуску (для автозапуску задай `QT_PREFIX` у `~/.profile` або у власній копії `~/.config/autostart/layout-fix.desktop`):

```bash
export QT_PREFIX="$HOME/Qt/6.12.0/gcc_64"
cmake -S . -B build -DCMAKE_PREFIX_PATH="$QT_PREFIX"
QT_PREFIX="$QT_PREFIX" /usr/bin/layout-fix
```

## Запуск і налаштування

У параметрах Cinnamon мають бути розкладки English (US) і Ukrainian. Якщо увімкнена Russian, демон також враховує її; коли слово підходить двом мовам, перемикання відкладається до наступного слова або виконується вручну через `Alt+Pause`.

```bash
./build/layout-fix
```

Другий запуск нічого не робить: одночасно працює лише один примірник.

У вікні **Налаштування…** (із меню трея) доступні:
- мінімальна довжина слова для автовиправлення;
- гарячі клавіші (`pause-key`, `undo-key`, `convert-key`) через пряме натискання комбінації (`QKeySequenceEdit`);
- список виключених вікон (`exclude`) із показом `WM_CLASS` останнього активного вікна і кнопкою **«Додати»**;
- список слів-винятків (`ignore-words`, без урахування регістру), які ніколи не автовиправляються.

Збережені зміни застосовуються одразу й пишуться у `~/.config/layout-fix/layout-fix.conf` (або у файл із `--config PATH`), не перезаписуючи `/etc/xdg/layout-fix/layout-fix.conf`. Розширені шляхи до словників (`dict-en`, `dict-uk`, `dict-ru`) задаються в конфіг-файлі (зразок у `config/layout-fix.conf`).

Популярні термінали (`gnome-terminal`, `terminator`, `xterm`, `alacritty`, `kitty`, `konsole`, `tilix`, `xfce4-terminal`, `wezterm`, `urxvt`, `mate-terminal`), менеджери паролів (`keepassxc`, `bitwarden`, `1password`), а також `cinnamon-screensaver`, `gcr-prompter` і сам `layout-fix` входять до типового списку винятків. Діалог пароля polkit малюється всередині Cinnamon і в цей список не потрапляє — перед ним увімкніть паузу.

### Особливості розпізнавання

- Автоматично виправляються зокрема українські й російські слова з літерами на клавішах пунктуації (`,`, `.`, `;`, `[`, `]`, `` ` ``, `\`, `"` → `б`, `ю`, `ж`, `х`, `ї`, `'`, `ґ`, `є`, `э`, `ъ`, `ё`), без хибного перемикання природної англійської пунктуації (`he,`, `hello.`, `[hello]`).
- Окреме коротке або двозначне (`uk`/`ru`) слово не чіпається. Контекст до чотирьох сусідніх слів виправляється разом (атомарно через буфер обміну зі збереженням його вмісту, щоб уникнути перестановки пробілів під IBus), щойно наступне слово однозначно визначає мову.
- Після зміни списку джерел у Cinnamon демон перечитує XKB і `GetInputSources`. Поки індекси `us`/`ua` та ввімкненої `ru` не узгоджені, виправлення призупиняється, а значок трея стає помаранчевим.

## Автозапуск

Автозапуск у Cinnamon працює через XDG Autostart: Debian-пакет і `cmake --install` встановлюють `/etc/xdg/autostart/layout-fix.desktop` (`OnlyShowIn=X-Cinnamon;`, `X-GNOME-Autostart-enabled=true`). Його можна увімкнути або вимкнути у стандартній програмі Cinnamon **«Програми автозапуску»** (Startup Applications).

Для встановлення вручну зі збірки:

```bash
sudo cmake --install build --prefix /usr
```

Якщо раніше у версіях `0.1–0.3.0` вмикався `layout-fix.service`, вимкни його одноразово:

```bash
systemctl --user disable --now layout-fix.service 2>/dev/null || true
rm -f ~/.config/systemd/user/layout-fix.service
```
